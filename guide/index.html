이용 가이드

파일 처리 전 알아두면 좋은 사용법과 제한 사항입니다.

이미지 작업

JPG·PNG·WebP 파일을 선택하고 원하는 도구의 옵션을 설정하세요. 처리 후 실제 결과 크기와 미리보기를 확인하고 개별 파일 또는 ZIP으로 저장할 수 있습니다. 움직이는 WebP, SVG, HEIC는 현재 지원하지 않습니다.

엑셀 작업

표준 XLSX 파일만 읽기 전용 분석합니다. 최적화는 검증 가능한 파일에 한해 내부 항목을 그대로 재압축합니다. 원본을 항상 별도로 보관하고 결과를 Excel에서 다시 열어 보세요.

브라우저 처리

선택한 파일 내용은 키미 파일랩 서버로 전송되지 않습니다. 큰 파일은 브라우저 메모리를 많이 사용하므로 모바일에서는 파일 수를 줄여 처리하세요.

ⓘ
파일은 현재 브라우저에서 처리됩니다.

대용량 파일은 기기 메모리에 따라 실패할 수 있습니다. 원본을 보관하고 결과를 확인해 주세요.
